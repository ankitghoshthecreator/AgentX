# ============================================================================
# ENVIRONMENT SETUP
# ============================================================================
# 1. Create .env from .env.example:
#    cp .env.example .env
#
# 2. Set required API keys:
#    - GOOGLE_SEARCH_API_KEY (from Google Cloud Console)
#    - GITHUB_TOKEN (from GitHub Settings → Developer settings)
#    - OPENAI_API_KEY (optional, for fallback embeddings)
#
# 3. Start Redis:
#    redis-server (or docker run -d -p 6379:6379 redis:7)
#
# 4. Download spaCy model:
#    python -m spacy download en_core_web_sm
#
# 5. Run tests:
#    pytest tests/ -v
#
# 6. Start agent:
#    python -m src.main query "Your query here"
#
# 7. Start dashboard:
#    streamlit run src/dashboard/app.py

# ============================================================================
# TROUBLESHOOTING
# ============================================================================
#
# Issue: sentence-transformers download fails
# Fix: export HF_HOME=/path/to/cache (huggingface models cache)
#
# Issue: Redis connection refused
# Fix: redis-server must be running: redis-cli PING
#
# Issue: spaCy model not found
# Fix: python -m spacy download en_core_web_sm
#
# Issue: Google API 403
# Fix: Verify GOOGLE_SEARCH_API_KEY in .env
#
# Issue: GitHub API rate limit
# Fix: Use GITHUB_TOKEN for authenticated requests (5000/hr vs 60/hr)
