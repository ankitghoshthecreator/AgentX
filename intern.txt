Agentic AI Engineer Intern
Take-Home Assignment
Role Overview
We are hiring an Agentic AI Engineer Intern to help design, build, and improve autonomous AI
agents capable of planning, reasoning, and using tools to complete multi-step tasks with minimal
human intervention.
1 Objective
Design and build a small but functional agentic AI system that can:
(a) Accept a high-level goal from a user,
(b) Autonomously decompose the goal into a sequence of steps,
(c) Use at least two distinct tools (e.g., web search, a calculator, a code executor, a file reader,
an API call) to accomplish sub-tasks,
(d) Self-correct when a step fails or returns an unexpected result,
(e) Produce a final, structured output/report summarizing what it did and why.
2 Important Constraint: No Provided Dataset
We will not provide any dataset, sample data, or fixed input/output pairs. You are
expected to:
• Choose your own goal/task domain (e.g., research summarization, travel planning, competi
tive analysis, code refactoring assistant, etc.), or pick from the example prompts in Appendix
A,
• Source any data your agent needs live, via public APIs, web search, or tools at inference time,
• Generate your own synthetic test inputs to validate the agent if needed,
• Clearly document any assumptions, mock data, or simulated tools used, and explain why.
This constraint is intentional: we want to evaluate your ability to build systems that work in the
real world without being handed a curated dataset.
1
3 Task Description
Build an agent (in Python, TypeScript, or a language of your choice) that:
1. Takes a natural-language goal as input (CLI, script, or simple UI — your choice).
2. Produces a visible planning trace (its intermediate reasoning/plan before acting).
3. Executes the plan step by step, calling tools as needed.
4. Handles at least one deliberately induced failure gracefully (e.g., a tool timeout, invalid API
response, or ambiguous instruction) and shows how the agent recovers or reports the failure.
5. Outputs a final structured result (e.g., JSON or Markdown report).
4 Deliverables
• Source code (GitHub repo or zip) with a working README (setup + run instructions).
• An architecture diagram (can be hand-drawn/exported image) showing agent components
and control flow.
• 2–3 sample run transcripts/logs showing the agent’s planning, tool calls, and final output.
• A short (1 page max) write-up covering: design decisions, limitations, and what you would
do differently with more time.
5 Time Limit
Suggested effort: 5–7 days, part-time. We care more about judgment and engineering quality
than raw feature count.
